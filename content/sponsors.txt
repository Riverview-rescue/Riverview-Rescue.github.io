# ============================================================
#  SPONSORS  -  shown in the "Our sponsors" section of the home page
# ============================================================
#
#  HOW TO ADD A SPONSOR
#  Copy the lines below, paste them at the bottom of this file,
#  and change the words after each colon:
#
#      [Sponsor]
#      Name: Smith Family Feed Store
#      Website: https://www.smithfeed.com
#      Note: Hastings, Nebraska
#      Logo: smith-feed.png
#
#      Name      the sponsor's name                              (required)
#      Website   where the box takes people when they click it   (recommended)
#      Note      one short line under the name                   (optional)
#      Logo      the file name of their logo picture             (optional)
#
#  - Sponsors appear on the site in the same order as in this file.
#  - To remove a sponsor, delete its whole block.
#  - Lines that start with # are notes like this one. The website ignores them.
#
#
#  HOW TO ADD A LOGO
#
#   1. Get the logo as a picture file from the sponsor. PNG or JPG both work.
#   2. Put the file in the folder:   assets/img/sponsors/
#      (on github.com: open that folder, click "Add file", then "Upload files")
#   3. Add a "Logo:" line to that sponsor with the file's name, for example:
#          Logo: smith-feed.png
#
#  You do not need to resize or crop anything.
#  - Any size works. A very large picture is shrunk automatically, so it
#    will not slow the page down. Your original file is never changed.
#  - Any shape works. Wide, tall or square logos are all fitted inside the
#    same space, never stretched and never cut off.
#  - Logos look best on a white or see-through background.
#  - Capital letters in the name don't matter: "Smith-Feed.PNG" finds "smith-feed.png".
#  - If the name is misspelled or the file is missing, the box simply shows
#    the sponsor's initials instead, the same as a sponsor with no logo.
#
