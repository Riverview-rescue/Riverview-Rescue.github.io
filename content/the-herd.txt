# ============================================================
#  THE HERD  -  the "Meet the herd" part of the home page
# ============================================================
#
#  This part has three kinds of block:
#
#      [Photo]              one picture in the photo wall
#      [Featured animal]    a box about one animal, with a picture and buttons
#      [In loving memory]   a dark box remembering an animal
#
#  To add one, copy a whole block and change its words.
#  To remove one, delete the block.
#
#  PHOTOS
#  - Put the picture file in the folder assets/img/ and type its name after "Picture:".
#  - "Title" is the bold words on the photo. "Caption" is the smaller line (optional).
#  - "Description" says what is in the picture, for people who can't see it.
#  - The wall arranges itself. The first two photos are the big ones;
#    it looks best with 2, 5 or 8 photos.
#
#  - Lines that start with # are notes like this one. The website ignores them.
#
# ============================================================
